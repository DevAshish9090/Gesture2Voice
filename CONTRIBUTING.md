# Contributing to Gesture2Voice

Thank you for considering a contribution.

## Before you begin

1. Search existing issues before opening a new one.
2. For a significant feature or design change, open an issue first to discuss the approach.
3. Never commit datasets, trained `.pkl` models, virtual environments, API keys, or personal recordings.

## Development workflow

1. Fork the repository and create a branch from `main`.
2. Create and activate a virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Make a focused change and test the affected workflow locally.
5. Keep commit messages clear and describe why the change is needed.
6. Open a pull request with a concise summary, test notes, and screenshots or a GIF for UI changes.

## Dataset contributions

Only contribute data that you have the right to share. Remove personal information and obtain consent from anyone visible in recorded media.

## Code style

- Prefer clear names and small functions.
- Add comments only where the intent is not obvious from the code.
- Keep the README accurate when changing installation, training, or user-facing behaviour.
